# RAHL XMD - WhatsApp Session Generator

![RAHL XMD](https://drive.google.com/uc?export=view&id=10byKTYe0w15PndJVkxknsQXoYsBC__u4)

RAHL XMD is a sophisticated web application for generating WhatsApp session IDs using QR codes or pairing codes. Built with Node.js and a modern animated UI.

## Features

- **Dual Authentication Methods**: Choose between QR code scanning or pairing code
- **Animated UI**: Smooth animations and transitions using GSAP
- **Real-time Updates**: Automatic session detection and polling
- **Secure Encoding**: Base64 encoded session strings
- **Responsive Design**: Works on desktop and mobile devices
- **One-click Copy**: Easy session ID copying to clipboard
